# UAET

## 简介

 **UART** （Universal Asynchronous Receiver/Transmitter，通用异步收发传输器）是一种 **硬件通信接口** ，用于在两个设备之间进行**串行、异步**的数据传输。它的核心作用就是 **把数据在“并行”和“串行”之间互相转换** 。

## 原理

UART 让设备通过**两根线（TX 发送，RX 接收）** 就能以约定好的速率（波特率）互相收发数据，且 **不需要共享时钟线** 。

## 行为

1. **发送数据**
   * 将 CPU 内部的并行数据（例如一个字节 `0x41`）逐位地串行输出到 TX 引脚上。
   * 每个数据帧通常包含：起始位（低电平）、5~9 位数据、可选的奇偶校验位、停止位（高电平）。
2. **接收数据**
   * 在 RX 引脚上采样电平，把串行的位流重新组装成并行字节，并通知 CPU 读取。
3. **提供电气/协议层抽象**
   * 软件只需向 UART 寄存器写入数据，UART 自动处理起始/停止位、校验、中断等。
   * 硬件层面通常配合 RS‑232、TTL、RS‑485 等电平标准（但 UART 本身不规定电平，只规定时序）。

## 应用

* **调试输出** （在操作系统开发中尤其常用）
  内核通过 UART 向主机串口终端打印日志，不需要显示器或网络。
* **GPS 模块、蓝牙模块、传感器** 等低速设备通信。
* **单片机和计算机之间的交互** （通过 USB‑TTL 转接板）。
